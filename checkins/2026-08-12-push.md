# Day 打卡 · DeFi 套利（Arbitrage）入门

- 日期：2026-08-12
- 主题：DeFi 套利入门

## 一句话

同一资产在不同市场/协议间的价格差，低买高卖吃差价。套利的本质不是发现价差，而是「价差 - 成本 > 0」的净收益判断。

## 四种套利形态

1. **DEX 价差套利**：同币 Uniswap vs Curve 价格不同，搬砖。最简单，bot 最卷，窗口最短。
2. **三角套利**：单 DEX 内 A→B→C→A 绕一圈，汇率乘积 ≠ 1 时触发。无需跨协议，但路径计算要快。
3. **跨链套利**：同币主网 vs L2 价差大，但过桥成本 + 延迟是主要门槛，资金占用时间长。
4. **闪电贷套利**：Aave/dYdX 借大额本金，一笔交易内「借 → 搬 → 还 + 手续费」。资金效率最高，Gas 最贵、逻辑要求最严。

## 三大隐形费用（套利被吃掉的钱）

| 成本 | 说明 |
|------|------|
| Gas | 跨链/闪电贷多笔交易，直接吃掉小价差 |
| 滑点 | 大额买入推高价格，实际成交价劣于报价 |
| MEV 税 | 三明治攻击，交易被 bot 夹在中间，白打工 |

## Agent 视角：套利天生适合 agent

1. 窗口只有几秒到几分钟，agent 可常驻轮询，人盯不过来。
2. 条件可编程：价差 > gas + 滑点 + 手续费 才执行。
3. 失败要能回滚/止损 —— 接上之前学的 Safe Execution 模式，知识点串起来了。

## 核心结论

机会发现只是第一步，成本模型和失败回滚才是能不能赚钱的分水岭。算不清成本，bot 就是给矿工和 MEV 机器人送钱。
