## 二、核心知识地图（五条主线）

### 1️⃣ 套利地图：机会在哪（模块 1，08-05）

- **AMM 定价**：`x × y = k`，价格 = 池子代币比例（`y/x`），不是挂单撮合；大额交易天然有价格冲击
- **七种套利结构**：
  - 单链原子：DEX 内三角套利 / 跨 DEX 价差套利
  - 跨链非原子：跨链搬运 / 稳定币脱锚
  - 非交易型：清算套利（盯抵押率）/ MEV（抢排序）
- **流动性深度**：价差必须乘以「可成交深度」才有意义——薄池里 1% 价差会被 5% 滑点吃掉；TVL ≠ 有效深度（V3 集中流动性）
- **区块确认**：以太坊 12s 出块 + mempool 公开 → 价差是移动靶，屏幕价差 90% 是幻觉

### 2️⃣ 净收益公式：能不能赚（模块 1，贯穿全程）

```
净收益 = 价差
  - swap fee × 交易次数
  - 价格冲击（滑点）
  - 所有链的 gas 费
  - 桥费（若跨链）
  - MEV 风险折扣（可能被抢跑）
  - 资金占用机会成本
```

### 3️⃣ LI.FI 路由引擎：怎么走最划算（模块 2，08-06）

- **LI.FI 不是 LP，是路由引擎**：聚合 27+ 桥、31+ DEX、Solver 网络、收益协议，只回答「从哪到哪」
- **对象层级**：`Quote`（单步即签）⊂ `Route`（多步比较）⊂ `Step`（swap/cross/lifi/protocol 原子操作）
- **路由报告 ↔ 成本层一一对应**：`toAmount`=价差、`toAmountMin`=滑点、`feeCosts`=桥费、`gasCosts`=gas、`executionDuration`=时间窗口
- **三目标权衡**：cheapest / fastest / safest——**套利场景下「最便宜 ≠ 最优」**，价差窗口短时多花 $5 保确定性反而正确
- **核心武器**：`POST /advanced/routes` 返回多条路由，逐条算净收益再排序

### 4️⃣ 执行成本五问：为什么不能只看两个价格（模块 3 Day1，08-07）

```
① 资金在哪里？  ② 走哪条路？  ③ 多久到达？  ④ 实际收到多少？  ⑤ 中间损耗多少？
```

- gas（跨链至少 2 笔）、桥费（固定成本，小额搬运必亏）、滑点（0.3% 价差可能被 0.5% 滑点反噬）、MEV（最便宜路径 = bot 最熟路径）、资金占用、失败交易
- **核心洞察**：发现价差只占套利流程 20%，**执行验证占 80%**。LI.FI 的价值不是找价差，而是把执行成本精确算给你看
- **Agent 接入四种方式**：REST API（脚本）/ MCP Server（LLM 原生）/ SDK（产品集成）/ CLI（调试）——Hermes 可直挂 LI.FI MCP

### 5️⃣ 信号工作流：怎么自动化（模块 3 Day2，08-08）

```
① 价格源采集 → ② 价差计算 → ③ LI.FI 报价 → ④ 净收益判断 → ⑤ 告警/信号
   CoinGecko      (askA-bidB)    /quote       toAmount-成本    净收益>阈值
   链上 RPC       -桥费-gas      /routes      -MEV折扣         →推送
```

- **数据源分层决策**：CoinGecko 粗筛（1-5min 延迟，够做漏斗）→ LI.FI 验证（全成本权威）→ 链上 RPC 精确（08-10 再上）
- **净收益判断闸门**：净收益 > $10 且收益率 > 0.3% 且 `executionDuration` < 价差窗口（粗版，08-13 精修）
- **算例实锤**：10,000 USDC Arb→Eth，毛价差 +0.15%（$15），LI.FI 桥费+gas ≈ -$18 → 净亏 $3 ❌

## 四、本周五大认知升级

1. **90% 的屏幕价差是幻觉**——不是不存在，而是在执行窗口中被抢/被吃/被吞
2. **毛价差不能决策**——必须经 LI.FI 报价把成本算进 `toAmount`，才是真净收益
3. **桥费是固定成本**——小额搬运天然不经济，信号阈值必须覆盖固定成本
4. **最便宜路径 ≈ bot 最熟路径**——冷门但稍贵的路径 gas 竞争低，成功率更高
5. **跨链同币净收益 = toAmount - fromAmount**——LI.FI 把费用全扣净，不用手工减
