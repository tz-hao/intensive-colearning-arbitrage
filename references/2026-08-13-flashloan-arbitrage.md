# 2026-08-13 学习笔记：闪电贷套利交易流程（Flash Loan Arbitrage）

## 一句话定义

无抵押借大额本金，在一笔交易内完成「借 → 交换 → 归还 + 手续费」，靠协议的原子性保证安全。昨天的套利入门里它是第 4 种形态，今天把流程拆开看。

## 完整交易流程（四步）

### 1. 借贷池：借
- 提供方：Aave / dYdX / Balancer / Uniswap v3 都有闪电贷。
- 无抵押的关键前提：同一笔交易内必须归还本金 + 手续费，否则整笔交易回滚。
- 手续费对比（选池子要算）：Aave 0.09%、dYdX 0.05%、Uniswap v3 0.05%、Balancer 0.01%。
- 理解要点：不是「借了可以不还」，而是「还不上就什么都没发生过」。

### 2. 交换：搬
- 用借来的钱在便宜市场买入，在贵市场卖出。
- 滑点保护：swap 时设 minAmountOut（最小输出量），实际成交低于预期直接失败，防止被坑。
- 路径：单跳 A→B，或多跳 A→B→C 串起来。

### 3. 归还 + 手续费
- 你的合约在回调函数里做完所有 swap 后，借贷池会检查余额：>= 本金 + 手续费？
- 不够 → revert，整笔交易回滚。

### 4. 利润结算
- 利润 = 卖出所得 - 本金 - 手续费 - gas。
- 利润为负 → 整笔回滚，只损失一笔失败的 gas 费，本金不亏。

## 为什么能无抵押借大额：原子性

EVM 的一笔交易要么全部成功、要么全部回滚。借贷协议在回调末尾强制检查还款，所以借出几亿美金也不需要抵押 —— 还款是协议强制的，不是靠信用。这就是闪电贷的核心魔法，也是和普通借贷最大的区别。

## 成本账（闪电贷专属）

| 成本 | 说明 |
|------|------|
| Gas | 一次套利通常 3-4 次调用（借 / swap×2 / 还），主网高峰期很贵 |
| 手续费 | 选池子要算，Aave 0.09% 最贵，Balancer 0.01% 最便宜 |
| 滑点 | 大额交易吃池子深度，利润必须按实际流动性算，不能按报价算 |

## Agent 视角：与 Safe Execution 的连接

- 原子回滚 = 天然的 Safe Execution：协议强制失败即回滚，不需要自己写补偿逻辑。
- 但利润判断必须在链下先算好（成本模型），链上只负责执行 —— 和昨天结论一致。
- 合约持币授权要最小化（approve 粒度）→ 呼应 Safe Session Key 的授权管理。
- 自己发起大额 swap 也可能被三明治攻击夹 → 明天深挖防御。

## 核心结论

闪电贷套利 = 用协议强制的原子性换「无抵押资金效率」。风险从「资金损失」变成了「逻辑错误整笔 revert」，所以合约逻辑要极严谨。
