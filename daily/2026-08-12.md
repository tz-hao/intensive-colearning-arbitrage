# 2026-08-12 学习笔记：DeFi 套利（Arbitrage）入门

> 主题：DeFi 套利入门速记 · 来源：每日推送学习
> 阶段：深度知识补充（Agent 架构模式 + DeFi 机制）

## 一句话定义

同一资产在不同市场/协议间的价格差，低买高卖吃差价。
赚的是「市场割裂」的钱 —— 套利的本质不是发现价差，而是「价差 - 成本 > 0」的净收益判断。

## 四种常见套利形态

### 1. DEX 价差套利（最简单，bot 最多）
- 同一个币，Uniswap 和 Curve 价格不一样，搬砖。
- 特点：实现最简单，竞争最激烈，机会窗口最短。

### 2. 三角套利
- 同一个 DEX 内部，A→B→C→A 绕一圈。
- 触发条件：汇率乘积 ≠ 1 时出现机会。
- 特点：单 DEX 内完成，无需跨协议，但要求路径计算快。

### 3. 跨链套利
- 同币在不同链上（ETH 主网 vs Arbitrum）存在价差。
- 门槛：赚完要过桥，跨链成本和延迟是主要门槛。
- 特点：价差往往更大，但资金占用时间长、风险高。

### 4. 闪电贷套利
- 用 Aave / dYdX 的闪电贷借大额本金。
- 一笔交易内完成「借 → 搬 → 还 + 手续费」。
- 特点：资金效率极高（无抵押大额本金），但 Gas 贵、逻辑要求严密。

## Agent 视角：为什么套利天生适合 agent 做

1. 机会窗口短（几秒到几分钟）—— 人要盯盘，agent 可以常驻轮询。
2. 判断条件可编程 —— 价差 > gas + 滑点 + 手续费 才执行。
3. 失败要能回滚/止损 —— 和之前学的 Safe Execution 模式直接挂钩。

## 必懂成本账（套利被吃掉的三大隐形费用）

| 成本 | 说明 |
|------|------|
| Gas | 跨链 + 闪电贷都要多笔交易，成本高，直接吃掉小价差 |
| 滑点 | 大额买入会把价格推高，实际成交价劣于报价 |
| MEV 税 / 三明治攻击 | 交易可能被别的 bot 夹在中间，白打工 |

成本模型算不清，bot 就是给矿工和 MEV 机器人送钱。

## 核心结论

套利 = 净收益判断：价差 - (Gas + 滑点 + 手续费) > 0 才执行。
机会发现只是第一步，成本模型和失败回滚才是能不能赚钱的分水岭。
