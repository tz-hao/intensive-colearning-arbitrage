## 一、精读：文章核心观点

> 「链上发现一个价差，只是套利流程的开始。最后能不能执行，要看**资金从哪里来、走哪条路、多久到达、实际收到多少**，以及**中间会损耗多少**。执行之前也不能只看两个市场的价格。至少要先拿到真实……」

### 一句话提炼

**价差是「毛收入」，执行链路是「成本项」，两者相减才是「净收益」。** 屏幕上的价差 ≠ 你赚到的钱。

### 「价差 → 净收益」的关键链路（文章隐含的完整链条）

```
① 发现价差          → 两个市场（或同市场不同池）的价格差
② 确认资金位置      → token 在哪个链？需要先 swap 还是桥？
③ 计算路径成本      → LI.FI 算：gas + 桥费 + DEX fee + 滑点
④ 估算时间窗口      → executionDuration vs 价差持续时间
⑤ 评估 MEV 风险     → 这条路径是不是 bot 密集区？
⑥ 得到净收益        → toAmount - 总成本 - MEV 折扣
⑦ 判断是否执行      → 净收益 > 阈值（否则不做）
```

**核心洞察**：套利不是「发现机会」，是「验证机会是否可执行」。发现价差的动作只占整个流程的 20%，剩下 80% 是执行验证。

## 二、LI.FI 四种 Agent 接入方式盘点

| 方式 | 接入途径 | 适用场景 |
|------|---------|---------|
| **REST API** | `https://li.quest/v1/*`（quote/routes/status/chains/tokens/tools） | **最快起步**：脚本/Agent 直接 HTTP 调用，无需 API Key，适合做信号验证和原型 |
| **MCP Server** | LI.FI 托管的 MCP 端点 | **LLM 原生**：Claude/Cursor/Hermes 等支持 MCP 的 Agent 直接「对话式」查报价、追状态，适合研究探索 |
| **SDK** | `@lifi/sdk`（npm, TypeScript） | **产品集成**：把 LI.FI 路由能力嵌进自己的应用/交易系统，完全控制执行流程，适合策略落地 |
| **CLI** | `npx @lifi/cli` | **终端快速查询**：人肉/脚本在命令行查一条报价，token 开销最小，适合调试和快速验证 |

### Agent 最小端点集（五个端点起步）

```
1. GET /quote    → 获取单条最优报价
2. GET /status   → 追踪跨链交易状态
3. GET /chains   → 链列表
4. GET /tokens   → Token 列表
5. GET /tools    → 桥和 DEX 列表
```

### 对 Hermes 的意义

Hermes 是 MCP 客户端——**可以直接挂 LI.FI 的 MCP Server**，让 Agent 拥有「查报价 → 比较路由 → 判断净收益」的链上套利能力。这正是模块 3 要搭的工作流核心。

## 三、思考题：为什么执行前不能只看两个市场的价格？

**Hint：gas、桥费、滑点、MEV**

表面上看，套利 = 市场 A 买 + 市场 B 卖，价差即利润。但实际执行要穿过层层「摩擦成本」：

### 1. Gas 费（所有链的燃料）
- 每笔交易都要付 gas，跨链套利 = 至少 2 笔（买 + 卖），跨链还可能有桥接费
- 例：价差 $10，但主网 gas 两笔加起来 $8 → 净收益只剩 $2

### 2. 桥费（跨链的过路费）
- 跨链必须走桥，桥收协议费 + 依赖流动性深度
- 例：Stargate 收 $5 固定费 + 0.06% 滑点费，小金额搬运直接亏

### 3. 滑点（你的交易自己推动价格）
- 大额交易会吃掉池子深度，实际成交价 ≠ 报价价
- AMM 里买 100 ETH 的均价远高于买 1 ETH
- **价差可能只有 0.3%，但你的交易滑点就 0.5% → 直接倒亏**

### 4. MEV（机器人抢跑）
- 你看到的价差，bot 也看得到，而且比你快
- 最便宜路径 ≈ 最多人用 ≈ 被夹概率最高（三明治攻击）
- 时间窗口：`executionDuration` 如果 > 价差存在时间，你到的时候价差已经没了

### 5. 还有隐性成本
- **资金占用**：桥接要等确认（几分钟到几十分钟），期间资金锁死
- **失败交易**：滑点设置太紧 → 交易失败 → gas 白付
- **跨链最终性**：有些桥需要挑战期/预言机确认

### 结论

```
只看两个市场的价格 = 只看收入，不看成本
真实的净收益 = 价差 - gas - 桥费 - 滑点 - MEV折扣 - 失败概率×gas

所以：执行前必须拿到「真实报价」→ 这就是为什么 LI.FI 的价值
不在于告诉你哪里有价差，而在于把执行成本精确算给你看
```
