## 要点与发现

1. **学到最硬的一条：成本是过滤器，不是修正项**。价差 2% 看着香，两腿 fee 0.6% + 滑点 + gas 一过，08-13 实跑 $5K 只净 +8.35，$10K 直接 -10.42。08-09 还踩了"固定费 $25"的认知坑，08-20 修正为 0.25% 比例费——这直接判了跨链日常搬运死刑（08-10 实测 6/6 全亏、08-18 纸面 5/5 IGNORE）。

2. **三假设收束成一个**：H1 同链 DEX 价差是唯一主策略（L2 + 毛价差 ≥2% + 单笔 ≤$5K + 池深 ≥$2M + 净 ≥$10 + 窗口 ≥10s）；H2 三角因 3×0.3% fee 太薄降观察；H3 降级为脱锚事件监控。

3. **踩的坑清单**：四天断更让"回测"永远停在参数扫描、没有历史回放（backtest_v2.py 不存在，如实写进 final.md）；08-20 桥费认知修正；08-23 风险审查逼出"不签名/不重试/不救单/不补发"四不原则。

4. **"沉默是设计"**：三道闸门全过才 ACTION，不满足就 IGNORE，误报是噪声、漏报才是风险。08-10 信号日报 0 触发 0 误报验证了这条。

5. **自我约束是最大产出**：缺历史价差数据 → 不上真金。策略包（final.md）第六节明写"回测不能回答机会多久出现一次"，这是 21 天里最值钱的一句。
