## 一、AMM 自动做市商

### 核心公式：x × y = k

- `x` = 池子里 Token A 的数量
- `y` = 池子里 Token B 的数量
- `k` = 恒定乘积（swap 过程中不变）

**价格由代币比例决定**，不是挂单撮合：
```
Token A 的价格（以 B 计价）= y / x
```

**例子**：ETH/USDC 池有 10 ETH + 20,000 USDC
- k = 200,000
- ETH 价格 = 20,000 / 10 = 2,000 USDC

### Swap 时的价格冲击

你买入时池子比例改变 → 实际成交价偏离当前显示价。交易越大，冲击越大。

用 2,000 USDC 在上述池子买 ETH：
```
(10 - Δx) × (20,000 + 2,000) = 200,000
Δx ≈ 0.91 ETH（而非按"标价"的 1 ETH）
```

→ 差额 0.09 ETH 就是价格冲击。

### AMM vs Order Book

| | AMM | Order Book |
|---|---|---|
| 对手方 | 池子（无对手方） | 其他交易者挂单 |
| 流动性 | 曲线上任意一点都可交易 | 依赖挂单深度 |
| 价格冲击 | 大额交易天然高滑点 | 看订单簿厚度 |
| 定价 | 公式自动算 | 买卖挂单撮合 |

## 二、七种套利结构

### 1. DEX 内三角套利

同一 DEX 三个交易对绕一圈：`USDC → ETH → UNI → USDC`

三个池子各自独立定价 → 绕圈隐含汇率可能 ≠ 1 → 套利空间。

**特点**：原子执行（单笔合约调用），无跨 DEX 风险。扣 3 × 0.3% swap fee 后利润薄。

### 2. DEX 间套利

同一链不同 DEX 同一代币对价差。便宜的池子买，贵的池子卖。

**特点**：需要 flash loan 或原子多步调用。MEV bot 重灾区。

### 3. 跨链套利

不同链同一资产价差：链 A 买便宜 → 跨链桥搬运 → 链 B 卖贵。

**致命缺陷**：非原子。桥确认期间价格可能变化。成本多一层桥费 + 价格风险。

适用场景：稳定币、高速桥（LayerZero/Stargate）、极端脱锚。

### 4. 稳定币套利

USDC/USDT/DAI 应 = $1，池子短暂偏离时套利。

**特点**：波动极小（0.1-0.5%），扣费后微利，靠大资金 + bot。真正大赚在脱锚事件（如 SVB 事件 USDC → $0.87）。

### 5. 清算套利

借贷协议借款人抵押率不足时，清算人替他还债、拿走抵押品 + 清算奖励（5-10%）。

**本质不同**：对手是人，不是池子。不需要等价差——盯抵押率触线即动手。竞争极激烈（bot 拼 gas）。

### 6. MEV（排序套利）

不是找价差，是抢交易排序。
- **三明治**：抢在别人大单前买 → 大单推高价格 → 立刻卖出
- **抢跑**：看到有利可图交易，复制一份给更高 gas 抢先执行
- **尾随**：大单后反向操作

**启示**：MEV searcher 和套利者抢同一块蛋糕。理解 MEV 才知道自己的套利交易随时可能被抢。

### 7. 统一视角

```
                  ┌─ 同 DEX 内三角套利
  单链（原子）──┤
                  └─ 跨 DEX 价差套利

                  ┌─ 跨链套利
  跨链（非原子）─┤
                  └─ 稳定币脱锚搬运

                  ┌─ 清算套利（盯抵押率）
  非交易套利 ────┤
                  └─ MEV（抢排序）
```

## 三、流动性深度：池子有多少"货"可以吃

AMM 的瞬时价格不回答一个关键问题：**这个价格能成交多少量**。

### 薄池 vs 厚池

同样 $2,000/ETH 的池子：

| | 薄池 | 厚池 |
|---|---|---|
| 规模 | 10 ETH + 20k USDC | 10,000 ETH + 20M USDC |
| 买 1 ETH 均价 | ~$2,100（滑点 ~5%） | ~$2,000.2（滑点 ~0.01%） |
| 屏幕价差 1% | 滑点吃掉全部利润 ❌ | 滑点可忽略，能赚 ✅ |

**结论**：价差本身不说明任何问题——得看价差在多大交易量上还存在。

### TVL ≠ 有效深度

- **Uniswap V2**：流动性均匀分布整条曲线 `[0, ∞]`，只有当前价格附近有用
- **Uniswap V3**：集中流动性，LP 在指定价格区间放钱 → 同样 TVL，有效深度远高于 V2

套利时只关心 **当前价格 ± 交易量范围** 那段流动性。

### 对净收益公式的影响

滑点不是常数——它跟你投入的**资金量**和池子的**深度曲线**绑定。优化套利 = 算出最优交易量，刚好榨干价差且不超过滑点反噬临界点。

## 四、区块确认：价差是移动靶

### 链不是实时的

以太坊 ~12s 出一个块。你的交易进入 mempool 后才可能被打包：

```
T=0s   发现价差，提交交易 → mempool
T=6s   别人也提交了同样的交易
T=12s  出块！矿工打包了别人的，不是你的
       → 价差被吃掉，你还付了 gas 😵
```

mempool 公开可见 → 你的交易意图暴露 → bot 抢跑。

### 三层时间损耗

```
看到价差 ─→ 签交易 ─→ 进 mempool ─→ 被打包
  ↑            ↑          ↑            ↑
 数据延迟   计算延迟   gas 竞争      12s 间隔
```

- **数据延迟**：RPC 节点可能慢 2-3 秒
- **mempool 可见**：bot 监听到后复制你的交易 + 更高 gas 插队
- **区块重组**：以为上链了，实际被 reorg 回滚

### 对套利地图的影响

```
屏幕价差（静态）
  → 时间窗口修正（抓取↔执行之间可能消失）
  → mempool 竞争修正（被看到就会被抢）
  → 区块位置不确定性（同块内顺序？）
```

**生存法则**：能活的套利要么快到绕过公开 mempool（Flashbots），要么利润薄到 bot 不屑抢，要么特殊到 bot 脚本没覆盖。

这也解释了为什么"屏幕价差 90% 是幻觉"——不是价差不存在，而是在执行窗口中被抢/被吃/被吞了。

## 五、屏幕价差 → 可执行净收益

**公式**：

```
净收益 = 价差
  - swap fee × 交易次数
  - 每次交易的价格冲击（滑点）
  - 所有链的 gas 费
  - 桥费（若有跨链）
  - MEV 风险折扣（可能被抢跑）
  - 资金占用机会成本
```

**关键教训**：90% 的屏幕价差扣除上述成本后为负或接近于零。真正能执行的套利需要：
- 大资金（摊薄 gas 占比）
- 低延迟执行
- 避开 MEV 竞争
- 或等待极端事件（脱锚 / 巨鲸砸盘 / 新池启动）
