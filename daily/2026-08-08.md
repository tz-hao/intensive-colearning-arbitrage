## 一、流水线架构（五环节）

```
① 价格源采集 → ② 价差计算 → ③ LI.FI 报价 → ④ 净收益判断 → ⑤ 告警/信号
   CoinGecko      (askA - bidB)    /quote        toAmount - 成本      净收益 > 阈值
   链上 RPC       - 桥费 - gas    /routes        - MEV 折扣           → 推送提醒
```

每环节的输入/输出：

| 环节 | 输入 | 输出 |
|------|------|------|
| ① 采集 | 链/合约地址列表 | 各市场实时价格 |
| ② 价差 | 两个市场价格 | spread（毛价差） |
| ③ LI.FI 报价 | 起链/目的链/token/金额 | toAmount + 费用明细 + 时长 |
| ④ 净收益 | 报价结果 | 通过/拒绝 二元信号 |
| ⑤ 告警 | 通过的信号 | 群聊推送 |

**核心认知**：② 的毛价差不能直接决策，必须经过 ③ 把成本算进去，才能得到 ④ 的真净收益。

## 二、数据源选择（今天的关键决策）

| 数据源 | 拿到的数据 | 延迟 | 用途 |
|--------|-----------|------|------|
| CoinGecko 聚合价 | 全局均价（不分链） | 1-5 min | 粗筛 |
| CoinGecko token_price | 某链某合约价格 | 1-5 min | 粗筛 |
| 链上 RPC (eth_call getReserves) | 池子实时储备 → 可成交价 | 实时 | 精确验证 |
| Subgraph | 历史池子数据 | 索引延迟 | 回测 |

**决策**：先跑通最小闭环 **CoinGecko 粗筛 → LI.FI 验证**。理由：
- 聚合价延迟 1-5 min 对「分钟级窗口」的套利不够精确，但足够做第一层漏斗
- LI.FI 报价自带全部成本（桥费+gas+滑点），是净收益的权威来源
- 链上 RPC 读池子代码量最大，留到 08-10 信号校准阶段再上

**RPC 读池子原理**（预研）：
```
reserve0, reserve1 = pair.getReserves()   # eth_call 只读调用
price_token0_in_token1 = reserve1 / reserve0
```

## 三、LI.FI 报价（工作流的心脏）

请求参数（设计期定死的字段）：

```
GET https://li.quest/v1/quote
  fromChain   = arbitrum
  toChain     = ethereum
  fromToken   = <USDC-Arbitrum 合约地址>
  toToken     = <USDC-Ethereum 合约地址>
  fromAmount  = 10000000000   # 10,000 USDC × 10^6 decimals
  fromAddress = <钱包地址>
  slippage    = 0.005
```

只关心 4 个返回字段：

| 字段 | 含义 |
|------|------|
| route.toAmount | 最终到账（已扣所有费用）→ 净收益核心 |
| estimate.gasCosts[] | gas 明细 |
| estimate.feeCosts[] | 桥费/DEX fee 明细 |
| estimate.executionDuration | 发起到到账秒数 → 和价差窗口比 |

**设计哲学**：跨链同币时净收益 = toAmount - fromAmount，LI.FI 把成本全算进 toAmount，不用手工减。

## 四、净收益判断（决策闸门）

```
净收益(USD) = toAmount(折算USD) - fromAmount(USD)
收益率      = 净收益 / fromAmount

触发条件（粗版，08-13 精修）：
  ① 净收益 > $10
  ② 收益率 > 0.3%
  ③ executionDuration < 预估价差存续时间
  ④ MEV 折扣：bot 密集区 → 预期收益 × 0.5 后再比阈值
```

**算例（示意值）**：
```
10,000 USDC：Arbitrum → Ethereum
  spread（毛）      = +0.15%  → 毛利 $15
  LI.FI 桥费+gas   ≈ -$18    → 净亏 $3 ❌
结论：桥费是固定成本，小额搬运永远亏 — 价差 ≠ 利润的实锤
```

## 关键收获

1. **毛价差不能决策**：必须经 LI.FI 报价把成本算进 toAmount，才是真净收益
2. **数据源分层**：CoinGecko 粗筛（快/糙）→ LI.FI 验证（准/全成本）→ RPC 精确（后置）
3. **跨链同币净收益 = toAmount - fromAmount**：费用已被聚合器扣净
4. **桥费是固定成本**：小额搬运天然不经济，信号阈值必须覆盖固定成本
