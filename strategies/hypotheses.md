## 假设 1：同链 DEX 价差（稳定币/主流币对）

**🎯 结构**：同一链上，同一代币对在两个 DEX 的报价出现瞬时价差 → 便宜池买、贵池卖（单链，无桥）

**⚡ 触发条件**：
```
价差 > swap fee(0.3% × 2) + 滑点 + gas + 目标利润(≥$5)
```

**💰 收益来源**：两个池子定价不一致——流动性深度不同 / 套利者尚未修复价差

**🪤 风险点**：
- 同链价差是 **MEV bot 主战场**，窗口可能 < 1 个块
- 滑点随资金量放大，薄池价差=幻觉（模块 1 第三节）
- 价差通常极小（0.1-0.5%），扣费后微利

**🔬 验证方式**：
- 用 LI.FI `/quote`（聚合最优价）作为"市场基准"，对比单个 DEX 直连报价（如 Uniswap V3 的 RPC/子图价格）→ 价差 = LI.FI 聚合价 vs 单池价
- 关键洞察：**LI.FI 是执行腿，检测腿要自己扫**——聚合器已经把大多数同链价差抹平了，真正能抓的是它覆盖不到的池子（新池/冷门 DEX）
- 回测（08-14）：扫历史报价，统计"价差 > 阈值"出现的频率和持续时间

**📌 证伪条件**：连续 3 天扫描，同链价差从未在扣费后为正 → 假设不成立，放弃

**🧩 与现有代码衔接**：`signal_scanner.py` 加同链场景（复用 `scan()` 函数，改场景参数）

## 假设 2：同链三角套利

**🎯 结构**：`USDC → ETH → UNI → USDC`（三个池子绕一圈，单链单合约）

**⚡ 触发条件**：
```
隐含汇率乘积 ≠ 1 且偏差 > 3 × swap fee(0.3%) + 滑点 + gas
```

**💰 收益来源**：三个池子独立定价，绕圈后的隐含汇率不平衡（模块 1 结构 1）

**🪤 风险点**：
- 扣 3 × 0.3% swap fee 后利润**极薄**（模块 1 已标注）
- 同链原子执行是优势，但 MEV bot 与你在同一战场
- 需要三个池子同时有足够深度

**🔬 验证方式**：
- LI.FI `/advanced/routes` 支持多 hop 路径 → 直接构造三角路径报价，`parse_route` 复用 08-09 逻辑
- 单笔合约原子执行 → 无桥风险、无跨链非原子风险（对比假设 3 的核心优势）
- 08-14 回测：随机时点采样三角路径，统计净收益分布

**📌 证伪条件**：采样 50 次三角路径报价，净收益从未 > 0 → 该结构在此链无利可图

**🧩 与现有代码衔接**：`lifi_routes.py` 的 `api_get`/`parse_route` 直接复用，新增三角路径场景

## 假设 3：跨链稳定币搬运（大单/脱锚模式）

**🎯 结构**：Arb 上 USDC 便宜 → LI.FI 跨链搬运 → Base/Eth 卖贵

**⚡ 触发条件**：
```
价差 > $25 固定费 + 桥费 + 滑点 + 目标利润
单笔 ≥ $8.3K（0.3% 目标才能摊薄固定费）
```
或：**稳定币脱锚事件**（如 2023 SVB 事件 USDC → $0.87，价差一次性拉大到数 %）

**💰 收益来源**：跨链间稳定币价差——多数时刻 ≈ 0，**脱锚/极端事件时显著**

**🪤 风险点**：
- 非原子：桥确认期间价格可能变化（模块 1 第四节"价差是移动靶"）
- $25 固定费必吃 → 小额交易 100% 亏（08-10 已实测 6/6）
- 桥故障/排队会吃掉时间窗口

**🔬 验证方式**：
- 08-10 已实测：无价差时刻 6/6 全亏 → 假设的验证核心是**"什么时候价差会出现"**
- 回测用历史事件数据：2023 SVB 脱锚、2024 各稳定币闪脱锚事件的价差幅度 vs 桥费
- 信号系统保持沉默是对的——**低频率大信号**是它的设定，不是 bug

**📌 证伪条件**：回测发现历史上稳定币价差从未超过 $25 + 桥费 + 滑点 → 此结构只属于脱锚黑天鹅，放弃日常执行，保留事件监控

**🧩 与现有代码衔接**：`signal_scanner.py` 现有跨链场景不变，加"脱锚监控"（稳定币全链对价 > 1% 即告警）

## 选型小结

| 假设 | 桥费 | 频率 | 利润 | 优先级 |
|------|------|------|------|--------|
| 1 同链 DEX 价差 | 无 | 中 | 薄 | 🥇 先做（门槛低，练手检测链） |

| 3 跨链搬运 | $25 | 极低 | 大 | 🥉 事件驱动（保留监控，不日常执行） |

**关键认知（08-10 日报 → 今天的转化）**：
1. 固定费约束把选型从"跨链优先"推向"同链优先"
2. 同链两条路径都是**薄利高频**路线 → 08-12 成本模型要精确到"滑点随资金量的曲线"
3. 假设 3 不是被放弃，而是**降级为事件监控**——与 08-13 的信号规则（净收益 > X 且窗口 > Y）天然契合
