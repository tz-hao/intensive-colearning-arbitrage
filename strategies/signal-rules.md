## 0. 总纲：一条公式 + 三道闸门

净收益公式（08-12 已落地为代码）：

```
net = spread × V − legs × (fee × V + slippage(V, 池深)) − gas − MEV折扣 − 固定费
```

三道闸门，缺一不可才触发执行：

1. 净收益闸门：net ≥ X（美元），X 随信号类型不同
2. 时间闸门：价差窗口 ≥ Y（秒），窗口太短 = 没时间执行，或已被 MEV bot 盯上
3. 风险闸门：MEV 风险低（p_mev ≤ 0.45）且池深达标（滑点 ≤ 毛价差 30%）

## 2. X 的推导过程（08-13 实跑 cost_model.py 记录）

### 2.1 0.6% 毛价差在 2M 池全量级无盈利点

```
链=base | 池深(USDC侧)=2,000,000 | 毛价差=0.6% | 腿数=2 | MEV 45%
  资金    500 → 净 -1.81  资金  1,000 → 净 -3.87
  资金  2,500 → 净 -11.68 资金  5,000 → 净 -30.15
  资金 10,000 → 净 -87.42 资金 50,000 → 净 -1,498.54
该参数组合下无盈利点——滑点+费用+MEV 已吃光毛价差
```

结论 1：08-11 假设里「价差 > 0.3%×2 + …」的 0.6% 触发线是错的——swap fee 0.6%（两腿）本身就把 0.6% 毛价差吃光了。同链触发阈值上调到毛价差 ≥ 2.0%。

结论 2：滑点爆炸点 $500 起（滑点成本 > 毛价差一半）——2M 池只能吃 ≤ $2.5K 的单，资金量是滑点的放大器，不是利润的放大器。

### 2.2 1.5% 毛价差 @ 2M 池：最高净 $1.08，不够闸门

```
资金 1,000 → 净 +1.08（全场最高）   资金 2,500 → 净 +0.69
资金 5,000 → 净 -5.40               资金 10,000 → 净 -37.92
盈利区间: ≤ $2,500；最佳单笔净收益 $1.08 @ $1,000
```

结论 3：1.5% 价差在 2M 池虽然账面转正，但最高净收益 $1.08 远低于 $10 闸门——执行一次的成本（轮询/签名/失败风险）都不止 $1。X=$10 意味着：要么价差 ≥ 2%，要么池子更深。

### 2.3 2.0% 毛价差 @ 2M 池：$5K 单净 $8.35，逼近闸门

```
资金  500 → 净 +2.04   资金 1,000 → 净 +3.83
资金 2,500 → 净 +7.57  资金 5,000 → 净 +8.35
资金 10,000 → 净 -10.42（滑点爆炸）
盈利区间: ≤ $5,000；最佳单笔净收益 $8.35 @ $5,000
```

结论 4：2.0% 是 2M 池下「够到 $10 闸门」的最低毛价差；且单笔上限 $5K（超过就滑点爆炸）。同链规则的执行画像 = L2 + 毛价差 ≥ 2% + 单笔 ≤ $5K + 池深 ≥ $2M。

### 2.4 深池救不了 fee：10M 池 @ 0.6% 仍全亏

```
资金 1,000 → 净 -3.43   资金 5,000 → 净 -19.25
资金 10,000 → 净 -43.94 资金 25,000 → 净 -150.69
```

结论 5：池子深 5 倍（10M）也没用——fee 是硬下限，价差必须 > 两腿 fee 才有意义。这直接否定了「找深池就安全」的直觉，价差本身是第一前提。

### 2.5 ETH 主网 gas 屠杀：$12.6/swap

```
GasModel(ethereum): 12.600 USD/swap | 资金 1,000 → 净 -3.92；资金 10,000 → 净 -34.30
```

结论 6：同链执行锁定 L2（base gas $0.018/swap，arb $0.044/swap）。主网同链价差是机构 MEV 战场 + gas 成本高一个数量级，个人直接排除。

  net < 0.5X，或窗口 < 0.5Y，
  或 p_mev > 0.6（热门池三明治高发）
  不记录、不告警（保持沉默是设计，不是 bug）
