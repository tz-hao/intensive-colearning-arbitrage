## 2. 信号规则（源自 `signal-rules.md`，08-13 实跑推导）

```
net = spread × V − legs × (fee × V + slippage(V, 池深)) − gas − MEV折扣 − 固定费
```

三道闸门，缺一不可：
1. **净收益闸门**：net ≥ $10（同链）
2. **时间闸门**：价差窗口 ≥ 10s（Base 块 2s，低于 10s 是 MEV bot 专属区间）
3. **风险闸门**：p_mev ≤ 0.45，滑点 ≤ 毛价差 30%，池深 ≥ $2M

动作分级：三闸门全过 = ACTION（执行前重新 `/quote` 复核）；部分满足 = WATCH（提高轮询频率）；明显不满足 = IGNORE（沉默是设计）。

## 3. 成本模型（`experiments/cost_model.py`，08-24 复核实跑）

2M 池、毛价差 2.0%、Base 链（gas $0.018/swap）：

```
资金 5,000 → 净 +8.35（最佳单笔，+0.17%）
资金 10,000 → 净 -10.42（滑点 1.59%，爆炸）
盈利区间 ≤ $5,000；滑点爆炸点 $5,000
```

10M 池、同价差：`$10K → 净 +33.06`，但资金上限必须随池深上调才成立。

**铁律**：价差必须 > 两腿 fee（0.6%）；池深只降滑点、不补价差（10M 池 @ 0.6% 仍全亏）；执行锁定 L2（主网 gas $12.6/swap 直接排除）。

## 5. 安全与风控（`security.md` + `risk-review.md`）

- **五道防线**：approve 最小化 / 执行专用热钱包（session key 理念）/ 合约白名单 / 单笔+日累计+频率限额 / 离线签名优先
- **广播前检查清单**：tx.to ∈ 白名单、approve 金额 == 报价、allowance 足够、限额未超、slippage 已设、签名恢复地址匹配、余额充足、日志落盘
- **四类失败场景**：价差消失 → 不签名标 EXPIRED；交易失败 → 不自动重试；被夹 → p_mev > 0.6 直接 IGNORE，不靠扩大滑点救单；桥故障 → 停发 + 告警 + 人工核对，确认失败前不补发
